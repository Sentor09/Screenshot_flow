# FlowSnap color palette

The palette is defined in `app/src/main/java/com/flowsnap/FlowSnapTheme.kt`. The app uses the light theme. Use semantic roles for app UI to keep colors consistent. Connector colors are saved user choices and are independent of the app theme.
